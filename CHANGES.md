# Changes

## v0.4.4

- The camp listing now has screenshots with captions and links to the user manuals and the issue
  tracker.
- A talk's track badge no longer overlaps its room and time line in narrow columns.
- Edit mode: room names in the column headers are readable (the capacity moves to its own line),
  and the Day start / Day end fields are wide enough for the whole time.
- The room and time label on span blocks and poster-session containers is readable on every
  colour theme.
- Pages no longer repeat the activity name (and, where Moodle's activity header already shows it,
  the description) under Moodle's own page header; page headings follow the activity header's
  heading level.

See `changelog.md` for the full development history.
